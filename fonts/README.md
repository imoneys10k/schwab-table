# Fonts

- Inter: bundled Latin WOFF2, SIL OFL, `OFL.txt`.
- Source Sans 3: unmodified variable TTF from https://github.com/adobe-fonts/source-sans/tree/release/VF ; SIL OFL in `SourceSans-OFL.md`.
- Droid Sans: unmodified TTF from https://android.googlesource.com/platform/frameworks/base/+/android-2.3.7_r1/data/fonts/DroidSans.ttf ; Apache 2.0 notice in `Droid-NOTICE.txt`.

The licences are preserved; font licences are separate from the project's MIT licence.
No proprietary fonts extracted from reference PDFs or copied from macOS are distributed.
Morgan prefers an installed MSGloriolaIIStd and otherwise Source Sans 3. Blackstone prefers Georgia/Trebuchet MS system fonts with documented fallbacks. Traditional Chinese uses system TC fonts. See `references/institutional-tables.md` for rendering differences.
