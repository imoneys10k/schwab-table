# 財報核對與解讀

每筆保留原始期間、幣別、單位與來源。10-Q的fy/fp是申報焦點，前期比較行也可能帶當期fy，必須核對實際日期。

單季損益優先直接披露的三個月數字。現金流常為累計：Q2＝六個月−Q1；Q3＝九個月−六個月；Q4＝全年−九個月。
兩條腿要同財年、同幣別、同一起點與定義，保留推導來源。Q4需核對重列；不能用全年EPS減九個月EPS，因為加權股數不同。
拆股與重列時，優先用本期披露的調整比較值。

資產負債表是時點。年結比較不是去年同季度；沒有同季資產負債表，不計同比。
Apple PDF的年結欄用來確認財年邊界，不冒充去年同季。

原始JSON用基礎幣別單位，例如94036000000 USD；圖表用百萬。EPS為幣別／股，利潤率為%，變動為百分點。
FCF＝CFO−購置PPE的現金支出，是明確定義的計算值，不冒充公司披露的非GAAP口徑。
同比／環比百分比只在基期大於零時算；零或虧損基期用原值／增減額解釋，不能套出誤導成長率。期間長度不同需註明。

綠▲／紅▼反映核心經營指標同比方向，不是買賣評級。研發、資本支出、現金與債務用中性▶，需要背景；不足比較資料為灰色—，不等於持平。

只有收入不能證明單位銷量增加；EPS成長要核對淨利與股本；現金流需看營運資金、現金稅與投入。
現金欄不含可交易證券，資料不足不能宣稱淨負債或流動性危機。

核對稅項、一次性費用／收益及GAAP／非GAAP調節附錄。基期一次性費用會放大本季同比；
不能把淨利或EPS的全部增幅歸因於營運改善，也不能把調整後比較值偷偷混入GAAP成長率。
PDF的supplemental_pages表示還有附錄需閱讀，不能只讀前三張主表就忽略調節說明。

一致預期須有發布前時間與可信來源，事件行情需對齊公告時點。缺失時聚焦已實現數據及公司披露，不判斷超預期或市場錯價。
